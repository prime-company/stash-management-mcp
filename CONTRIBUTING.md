# Contributing

Thanks for your interest! A quick note on how this repo works:

**This repository is a read-only mirror.** The source of truth lives in the
Stash Management private monorepo and is published here automatically, so pull
requests opened against this repo can't be merged and will be closed.

**Found a bug, or have a question or feature request?** Please
[open an issue](https://github.com/prime-company/stash-management-mcp/issues) —
that's the best way to reach us, and we read every one.

For product help, see
[stashmanagement.com/help](https://www.stashmanagement.com/help/ai-connections).
